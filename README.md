# 싸강 완료 알림

대구가톨릭대학교 iLOS 온라인 강의의 재생 완료를 감지해 Windows 경고창으로 알려주는 Chrome 확장 프로그램입니다.

강의 화면에 배너를 추가하지 않으며, 음성 안내도 사용하지 않습니다. 완료 시 Windows 네이티브 경고창이 항상 위에 표시되고 `확인`을 눌러야 닫힙니다.

## 지원 환경

- Windows 10/11
- Google Chrome
- `https://lms.cu.ac.kr/`의 iLOS 온라인 강의

## 설치

1. GitHub의 **Code → Download ZIP**으로 내려받고 압축을 풉니다.
2. `설치하기.cmd`를 더블클릭합니다.
3. 자동으로 열린 `chrome://extensions/`에서 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 압축을 푼 폴더를 선택합니다.
5. LMS 강의 탭을 새로고침합니다.
6. 확장 프로그램 아이콘을 눌러 **알림 테스트**를 실행합니다.

설치 스크립트는 관리자 권한 없이 현재 Windows 사용자 계정에만 네이티브 메시징 호스트를 등록합니다. 경고창 프로그램은 `%LOCALAPPDATA%\SgangLectureAlarm`에 설치됩니다.

## 사용

- 평소처럼 강의를 재생하면 됩니다.
- 확장 프로그램 배지에 현재 재생률이 표시됩니다.
- 영상 종료, 남은 시간 0초, 예상 종료 타이머, 종료 직전 강의 창 닫힘을 함께 감지합니다.
- 완료되면 항상 위에 고정된 Windows 경고창이 표시됩니다.
- Chrome을 완전히 종료하면 강의 감지도 종료됩니다.

## 업데이트

1. 새 버전을 내려받아 기존 폴더에 덮어씁니다.
2. `설치하기.cmd`를 다시 실행합니다.
3. `chrome://extensions/`에서 이 확장 프로그램의 새로고침 버튼을 누릅니다.

## 제거

1. `제거하기.cmd`를 실행합니다.
2. `chrome://extensions/`에서 **싸강 완료 알림**을 삭제합니다.

## 개인정보 및 동작 범위

- `lms.cu.ac.kr`에서만 강의 재생 상태를 읽습니다.
- 로그인 정보, 강의 내용, 재생 주소를 외부로 전송하지 않습니다.
- 외부 서버나 분석 도구를 사용하지 않습니다.
- 강의를 자동으로 넘기거나 출석 버튼을 누르지 않습니다.
- Windows 경고창 연동 소스는 [`native_host/Program.cs`](native_host/Program.cs)에 포함되어 있습니다.

## 개발 및 검사

```powershell
node tests/logic.test.js
node tests/package.test.js
```
