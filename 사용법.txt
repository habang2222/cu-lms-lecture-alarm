싸강 완료 알림 2.2
====================

[처음 한 번만 설치]

1. 이 폴더의 "설치하기.cmd"를 더블클릭합니다.
2. 열린 Chrome 확장 프로그램 화면 오른쪽 위의 "개발자 모드"를 켭니다.
3. 왼쪽 위 "압축해제된 확장 프로그램을 로드합니다"를 누릅니다.
4. 다운로드해서 압축을 푼 이 폴더 자체를 선택합니다.
5. 현재 열어 둔 싸강 탭으로 돌아가 새로고침(F5)합니다.

"설치하기.cmd"가 Windows 경고창 연동도 현재 사용자 계정에 자동으로 등록합니다.

[사용]

- 평소처럼 강의를 재생하면 됩니다.
- 툴바의 확장 프로그램 아이콘 배지에 재생률이 표시됩니다.
- 영상이 끝나거나 남은 학습시간이 0초가 되면 확인 버튼을 눌러야 닫히는 Windows 경고창으로 알려줍니다.
- LMS 페이지 안에는 알림 배너나 버튼을 표시하지 않습니다.
- 별도 상시 실행 프로그램 없이 Chrome이 종료 순간에 Windows 경고창을 직접 실행합니다.
- 다른 강의도 주소가 같아도 괜찮습니다. 현재 페이지 안의 실제 재생기를 찾아서 감지합니다.
- 확장 프로그램 아이콘을 누르면 현재 감지 상태와 진도를 볼 수 있습니다.
- 처음에는 팝업의 "알림 테스트" 버튼으로 Windows 경고창이 나오는지 확인하세요.

[안 울릴 때]

1. 강의 탭을 한 번 새로고침합니다.
2. 확장 프로그램 팝업에 "재생 중"과 퍼센트가 표시되는지 봅니다.
3. "설치하기.cmd"를 다시 실행해 Windows 경고창 연동을 복구합니다.
4. Chrome을 완전히 종료하면 감지도 끝납니다. 강의를 듣는 동안 Chrome은 켜 두세요.

[개인정보]

- lms.cu.ac.kr 페이지에서만 작동합니다.
- 로그인 정보, 강의 내용, 재생 주소를 외부로 전송하거나 저장하지 않습니다.
- 강의를 자동으로 넘기거나 출석 버튼을 대신 누르지 않고, 완료 시점만 알려줍니다.
